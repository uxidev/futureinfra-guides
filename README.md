## 구성

별도 설치나 빌드 과정 없이 제공하는 정적 HTML입니다. 각 페이지에 CSS와 구조화 데이터를 포함했으며 외부 폰트, 추적 스크립트, 폼을 사용하지 않습니다. 예제에는 실제 API 키나 비공개 소스가 포함되어 있지 않습니다.

예정된 GitHub Pages 주소는 [uxidev.github.io/futureinfra-guides](https://uxidev.github.io/futureinfra-guides/)입니다. canonical, Open Graph URL, 구조화 데이터와 sitemap이 이 경로를 기준으로 설정되어 있습니다. 저장소명이나 주소를 바꾸면 함께 수정해야 합니다.

`sitemap.xml`에는 HTML 페이지 5개의 주소가 들어 있습니다. `.nojekyll`은 HTML 파일을 그대로 제공하기 위한 표시입니다. 프로젝트 폴더 안의 `robots.txt`는 호스트 루트의 크롤링 정책을 대신하지 않습니다.
