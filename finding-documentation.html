문제를 세 단계로 나눠 봅니다

연결이 안 될 때

요청 주소와 인증 방식을 먼저 확인합니다. REST API의 기본 주소는 https://futureinfra.ai/v1, MCP 주소는 https://futureinfra.ai/v1/mcp입니다. 일반 홈페이지 주소를 API 주소처럼 사용하고 있지 않은지 확인하세요.

연결은 되지만 작업이 거부될 때

응답의 오류 코드, 현재 조직, 부여된 권한과 한도를 함께 봅니다. 권한 부족·잔액 부족·승인 대기는 대응 방법이 다릅니다. 같은 요청을 반복하기 전에 공식 오류 안내에서 원인을 좁힙니다.

배포는 됐지만 기능이 안 될 때

배포 버전, 필요한 환경변수, 외부 서비스 연결, 앱 로그를 순서대로 확인합니다. 실제 접속한 URL과 화면에서 수행한 작업을 기록하면 문의할 때 재현 조건을 전달하기 쉽습니다.

문의 전에 준비할 정보

  • 언제, 어느 기능에서 문제가 발생했는지
  • 예상한 결과와 실제 결과
  • 오류 코드나 요청 식별자처럼 문제를 찾는 데 필요한 정보
  • 이미 확인한 항목과 재현 순서

비밀번호·인증 코드·전체 API 키는 문의 본문이나 공개 화면에 넣지 않습니다. 화면을 첨부할 때는 개인 정보와 비밀값을 가린 뒤 확인하세요.
