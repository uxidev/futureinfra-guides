퓨쳐인프라 서비스 안내 · 2026년 10월 28일 공개 정보 확인

서버 사양과 함께 관리 화면의 접속 조건, 실제 사용 비용, 데이터 복구 방법을 살펴보세요. 퓨쳐인프라 서버를 검토하는 분을 위해 공식 안내를 정리했습니다.

1. 관리 화면에 접속할 수 있나요?

퓨쳐인프라 콘솔은 국내에서만 접속할 수 있습니다. 해외에서 관리해야 한다면 필요한 작업이 가능한지 먼저 문의하세요. 서버는 국내 자체 IDC에서 운영됩니다.

2. 사용 기간과 부가 비용을 함께 계산했나요?

표시된 월 요금은 730시간 기준이며 부가세가 포함되어 있습니다. 실제 서버 요금은 분 단위로 계산됩니다. 필요한 CPU·메모리·디스크 용량을 정한 뒤, 기본 트래픽 제공량과 초과 아웃바운드 요금, 추가 디스크·서버 이미지·백업 비용을 함께 살펴보세요. 인바운드와 같은 계정 서버 간 내부망 전송은 무료로 안내됩니다.

3. 정지와 삭제의 차이를 알고 있나요?

서버를 꺼도 디스크와 주소 같은 자원이 남아 요금이 발생합니다. 공식 안내에 따르면 2026년 11월 3일부터는 정지 중 요금제 기본 요금의 50%가 부과됩니다. 부가 항목은 별도 조건을 확인하세요.

삭제 전에 데이터를 보관하세요.

서버를 삭제하면 해당 서버 과금은 멈추지만 필요한 파일과 데이터베이스를 먼저 내보내고, 복원할 수 있는지 확인해야 합니다.

4. 접속과 공개 범위를 정했나요?

Debian·Ubuntu 서버의 root SSH는 관리자 권한으로 접속하는 방식입니다. SSH 키를 준비하고, 방화벽에서는 웹 서비스와 관리에 필요한 포트만 여세요. 무료 고정 공인 IP는 외부에서 서버에 접근할 때 사용하는 주소이며, IP를 배정하는 것만으로 방화벽 포트가 열리지는 않습니다.

5. 복구까지 확인했나요?

변경 전 스냅샷, 별도 백업, 실제 복원 절차를 구분해 준비하세요. 어떤 데이터가 사본에 포함되는지, 원본 서버를 잃어도 복구할 수 있는지 확인합니다. 백업의 보관 기간과 과금 조건도 구매 전에 살펴보세요.

내 용도에 맞는 서버와 요금 확인하기

개발 환경, 웹 서비스, API 운영에 필요한 자원을 정했다면 현재 상품과 요금 조건을 직접 확인하세요.
