04 · MCP 연결

Claude Code에 FutureInfra 연결하기

4분 읽기 · 공개 문서 확인 2026-10-02

FutureInfra의 MCP 연결은 AI 도구가 서비스의 기능을 사용할 수 있게 하는 연결 방식입니다. 브라우저 인증을 지원하는 환경에서는 키를 채팅에 붙여 넣지 않고 계정과 권한을 연결할 수 있습니다.

1. 원격 MCP 주소를 등록합니다

Claude Code를 사용할 수 있는 터미널에서 다음 공식 연결 명령을 실행합니다. 이 명령에는 비밀번호나 API 키가 들어 있지 않습니다.

claude mcp add --transport http futureinfra https://futureinfra.ai/v1/mcp

이미 같은 이름의 연결이 있다면, 기존 연결이 어느 조직에 사용되는지 먼저 확인하세요. 여러 조직을 사용하는 경우 연결 이름과 대상 조직을 구분해 관리합니다.

2. 브라우저에서 인증합니다

Claude Code에서 /mcp를 열고 FutureInfra 연결을 진행합니다. 브라우저에서 로그인하거나 가입한 뒤 연결할 조직과 허용할 권한을 확인합니다. 비밀번호·추가 인증 코드 입력과 권한 승인은 사람이 해당 페이지에서 직접 처리합니다.

연결 주소

https://futureinfra.ai/v1/mcp

FutureInfra는 OAuth와 Bearer API 키 인증을 제공합니다. 익명으로 모든 기능을 실행하는 서버는 아닙니다.

3. 조직과 권한을 확인합니다

연결이 끝나면 현재 조직이 의도한 대상인지 확인하고, 먼저 조회 중심의 작업으로 시작합니다. 생성·변경 작업을 맡기기 전에는 필요한 권한과 월 한도를 확인하세요. 결제·동의·되돌리기 어려운 작업은 별도의 사람 확인 절차를 따릅니다.

도구가 새로 추가되거나 인증 정보를 바꿨는데 클라이언트에 반영되지 않았다면, 공식 안내에 따라 AI 클라이언트를 다시 시작해 연결 상태를 확인합니다.

자동화 환경에서는 API 키 방식을 사용합니다

브라우저를 열기 어려운 CI나 자동화 환경은 공식 문서의 API 키 연결 방식을 참고할 수 있습니다. 실제 키는 사용하는 프로그램의 비밀값 설정에 저장하고, 필요한 조직·권한·한도를 제한합니다. 공개 예제에는 실제 키를 넣지 않습니다.

인증 화면에서 막히면 확인할 것

  • 공식 문서에 적힌 주소로 연결했는지
  • 선택한 조직과 요청한 권한이 맞는지
  • 브라우저 로그인을 마친 뒤 클라이언트로 돌아왔는지
  • 콘솔 접속 지역 제한에 해당하는지

FutureInfra는 콘솔을 국내에서 접속하도록 안내합니다. 해외에서 브라우저 인증을 시도하는 경우 이 조건을 먼저 확인하세요. API 키 연결 조건은 공식 API 문서에서 별도로 확인할 수 있습니다.

확인한 공식 안내

아래 공개 문서를 바탕으로 작업 순서를 정리했습니다. 서비스 조건이 바뀌면 최신 공식 안내를 확인하세요.

  • FutureInfra 공식 MCP 연결 안내
  • 인증·접속 조건을 포함한 API 문서
